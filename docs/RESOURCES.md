# Outside code and art: sources and rules

| Source | What it is | Use |
| --- | --- | --- |
| pret (pokefirered, pokeemerald) | Decompilations; the base of this repo | Already the foundation |
| RHH pokeemerald-expansion / pokefirered-expansion | Modern mechanics, debug, followers, configs | Already the base; check its configs before adding anything |
| Community feature branches (RHH, PokeCommunity) | UI and battle add-ons made for the expansion | Merge only with the author's terms; record in CREDITS.md |
| PokeCommunity / Eevee Expo (Relic Castle) resources | Sprites, tiles, UI packs | Follow each pack's credit terms |
| The Spriters Resource | Ripped official sprites (e.g. HGSS overworlds) | Nintendo/Game Freak/TPC property; use as fans do, credit the rippers |

Rules: credit everything in CREDITS.md before merging (author, link, terms); no closed-source hack code (e.g. Radical Red's CFRU base cannot merge into a decomp anyway); distribute patches only, never ROMs; non-commercial.
